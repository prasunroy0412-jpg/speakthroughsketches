# Speak Through Sketches

Static portfolio website built for GitHub Pages.

## Preview
Open `index.html` locally, or serve the folder with a simple local web server.

## Before going live
- Replace placeholder YouTube/social/email links.
- Add real Stories content.
- Add Google Analytics only after creating your property.
- Add AdSense code and `ads.txt` only after Google supplies your publisher details.
- Replace the privacy placeholder with a policy matching the services actually used.
- Configure GitHub Pages and verify the custom domain before changing DNS away from Google Sites.
